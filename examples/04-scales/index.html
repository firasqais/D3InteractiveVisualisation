Big idea 3: scales

A scale is a function. Give it a data value and it returns a pixel position, a width or a colour. The domain is the data space you choose; the range is the pixel (or colour) space you have. Pick the scale type from the data type.

d3.scaleLinear() for quantities (revenue)


  


  

    
d3.scaleBand() for categories laid out in slots (store names)

    

      
      
      
    

    

    

  


  

    
d3.scaleOrdinal() for categories mapped to colours (regions)

    

      

        
        
        
      

    

    

    

    

  


  

    
Match the scale to the data type

    

      
DataTypeScale

      
        
Revenue, targetQuantitative (ratio)scaleLinear, domain starting at 0 for bars

        
Store name on an axisNominalscaleBand (bars) or scalePoint (dots)

        
Region as a colourNominalscaleOrdinal with distinct hues

        
Satisfaction 1–5OrdinalPosition, or a sequential (light→dark) colour

        
Circle sizeQuantitativescaleSqrt, so area is proportional to the value
