What to notice

    
    
      
  • d3.select() finds the first match for a CSS selector; d3.selectAll() finds them all.
        Both return a selection, an object that wraps the elements.
    • 
      
  • .append() returns a new selection (the child). .attr() and .style()
        return the same selection, which is why you can keep chaining with dots. Read each dot as "and then".
    • 
      
  • After step 3 the circle exists in the DOM but you can't see it: its radius defaults to 0. After step 4 it is black,
        the default fill. Always set sizes and colours explicitly.
    • 
      
  • Events use the D3 v6+ signature (event, d) => …. Old tutorials use d3.event, which no longer exists.
