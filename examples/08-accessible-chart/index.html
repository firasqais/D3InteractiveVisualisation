D3 Interactive Visualisation / 08

An accessible interactive chart

Interaction that needs a mouse shuts people out. This chart works with a keyboard and a screen reader, names every colour, offers the same numbers as a table, and calms its motion for people who ask for less.

Keyboard: press Tab to reach the bars, then ← → to move between stores.

The checklist this chart follows

NeedHow it's done in chart.js
A text alternative<title> and <desc> inside the SVG, linked with aria-labelledby; the description is written from the data.
Keyboard accessEach bar gets tabindex and an aria-label; arrow keys move focus; focus shows the same tooltip as hover.
Colour is never the only cueA legend names every region, and the tooltip and table repeat it in words.
The numbers without the picture"Show as table" reveals a real <table> with the same rows.
Changes are announcedAn aria-live region says what changed after sorting.
Less motion on requestTransitions drop to 0 ms when the user's system has Reduce motion turned on.
