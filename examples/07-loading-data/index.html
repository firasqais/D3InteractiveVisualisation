Loading and shaping data

Real charts don't start with a hard-coded array. They load a CSV or JSON file, convert the types, then reshape the rows into what the chart needs. Here we load data/stores.csv and roll the 12 stores up into 4 regions.

1. Load and convert types

const rows = await d3.csv("../../data/stores.csv", d => ({
  store:   d.store,
  region:  d.region,
  revenue: +d.revenue,   // CSV values are strings: "4.8"
  target:  +d.target     // the + turns them into numbers
}));

2. Reshape: group and sum

      
const byRegion = d3.rollups(rows,
    v => ({ revenue: d3.sum(v, d => d.revenue),
            target:  d3.sum(v, d => d.target) }),
    d => d.region)
  .map(([region, s]) => ({ region, ...s }));

Why this example needs a local server

    
Browsers block d3.csv() and d3.json() for pages opened straight from disk (file://).
      Run a local server from the repository folder, for example python3 -m http.server 8000 or VS Code's
      Live Server, then open http://localhost:8000/examples/07-loading-data/. On GitHub Pages it just works.

    
Other useful loaders: d3.json(), d3.tsv(), and d3.autoType as a shortcut row converter.
      Useful reshapers: d3.group(), d3.rollup(), d3.sum(), d3.mean(), d3.bin().
