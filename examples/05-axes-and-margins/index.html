Axes and the margin convention

Every D3 chart starts the same way: define the margins, work out the inner width and height, and draw everything inside a <g> shifted by the margins. Axes live in that margin. Then comes the honesty test: D3 will happily draw a misleading chart if you tell it to.

Dashed border = the SVG. Shaded area = the plot group g, shifted by the margins.

What to notice

    
    
      
  • Shrink the left margin and the y-axis labels fall off the edge of the SVG. Shrink the bottom margin and the store names are cut.
    • 
      
  • Untick Start y at zero. The code switches from [0, d3.max(…)] to d3.extent(…), so the axis
        starts at the smallest value. Dubai's bar now looks about 18 times KL's, although the data ratio is 2.3. That's a
        Lie Factor of about 8 (Tufte, 2001). One word in the code, extent, made the chart dishonest.
    • 
      
  • Untick .nice(): the axis stops at an awkward value with no labelled top tick. .nice() rounds the domain to clean tick values.
    • 
    

    
D3 draws whatever you tell it to. Honesty is your job.
